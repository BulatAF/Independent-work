# Форма авторизации

Учебный проект: форма входа на чистом HTML + CSS + JS.

## Запуск

Открыть `index.html` в браузере. Или через сервер:

```bash
python3 -m http.server 8000
```

и открыть http://localhost:8000

## ❓ Доступность (accessibility)

- **`<label for>` + `id`** — каждое поле и чекбокс связаны с подписью, скринридер читает их вместе, клик по надписи фокусирует инпут.
- **Семантика** — `<header>`, `<main>`, `<footer>`, `<form>`, `<h1>`, `<h2>` дают скринридерам структуру страницы.
- **`lang="ru"`** — правильное произношение.
- **`autocomplete="email"` / `"current-password"`** — автозаполнение и подсказка для вспомогательных технологий.
- **`required`** — поля email и пароль помечены обязательными.
- **`type="button"` у кнопок соцсетей** — чтобы они не отправляли форму.

## ❓ Обоснование вёрстки

Вёрстка сделана **блочной (block)**, без grid и flex. Это осознанный выбор.

- **Каркас страницы — обычный поток блоков.**  
  `<header>`, `<main>`, `<footer>` — блочные элементы. Они и так идут друг под другом сверху вниз: шапка сверху, контент по центру, подвал снизу. Ничего дополнительно для этого делать не нужно — браузер сам выстраивает их в правильном порядке.

- **Форма — тоже вертикальный поток.**  
  Кнопки, поля, галочка и ссылки в форме идут друг под другом. Это ровно то поведение, которое `<form>` и его дочерние элементы дают по умолчанию: каждый блочный элемент занимает свою строку. Поэтому не нужны ни `flex-direction: column`, ни `grid-template-rows`.

- **Инпуты и кнопки — строчно-блочные (`inline-block`).**  
  Они по умолчанию ведут себя как строчные элементы с возможностью задать размеры. Это удобно, когда нужно разместить их в строку (например, кнопка + кнопка), не прибегая к flex.

- **Почему не flex/grid?**  
  Задача — простая вертикальная форма. Flex и grid дают мощные инструменты для сложных раскладок (многоколоночность, выравнивание по двум осям, адаптивная сетка), но здесь они избыточны. Блочная вёрстка читается проще, требует меньше CSS и не создаёт лишних обёрток.

Итог: **block — там, где нужен естественный поток документа; ничего сложнее не требуется.**
